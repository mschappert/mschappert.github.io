# mschappert.github.io

A static GitHub Pages starter site for a portfolio, resume, searchable resource library, and writing.

## Publish it

1. Create a GitHub repository named exactly `mschappert.github.io`.
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages** and select **Deploy from a branch**, then choose `main` and `/ (root)`.
4. Your site will be live at `https://mschappert.github.io` after GitHub finishes publishing.

## Make it yours

- Update the intro, projects, links, and email in `index.html`.
- Add your resume PDF to this folder as `resume.pdf`.
- Change or add resources in the `resources` list at the top of `script.js`. Each resource has a title, description, type, format, and URL.
- Replace the sample project cards and post links with your work and guides. For a larger site, create separate pages such as `blog/my-guide.html` and link to them from the cards.

There is no build step or server required; it is ready for GitHub Pages as-is.
